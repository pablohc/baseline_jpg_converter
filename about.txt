Baseline JPEG Converter v2.0.0
==============================

Converts EPUB images to baseline JPEG format (max 480x800) and fixes
SVG-wrapped images for compatibility with Crosspoint Reader and other
e-readers that don't support progressive JPEG or SVG-wrapped images.

Features:
---------
- Converts book covers and internal EPUB images to baseline JPEG
- Resizes images to max 480x800 pixels (maintains aspect ratio)
- Fixes ALL SVG-wrapped images (not just covers)
- Ensures proper cover meta tags in OPF files
- Handles PNG, GIF, WebP, and BMP conversions
- Creates .x4.epub output files

Usage:
------
Plugin (Calibre):
1. Select one or more books in Calibre library
2. Click "Baseline JPEG Converter" button
3. Converted books get an additional EPUBX4 format

Standalone:
python standalone/convert_epub.py book.epub
python standalone/convert_epub.py /path/to/epubs/
